# AI-Based Tax Calculation System

## Overview

The AI-Based Tax Calculation System is a web-based application developed to simplify income tax calculation under the Indian taxation system. The application allows users to calculate and compare tax liabilities under the Old Tax Regime and New Tax Regime, receive intelligent tax recommendations, and securely manage their tax calculation history.

The system uses rule-based intelligent decision logic to analyze user inputs and recommend the most beneficial tax regime based on income and deductions.

## How to Run the Project

### Backend

1. Open Backend in VS Code.
2. Configure MySQL database settings in application.properties.
3. Install Maven dependencies.
4. Run the Spring Boot application.

### Frontend

1. Open the Frontend folder.
2. Launch index.html using Live Server.
3. Register a new account.
4. Login and start calculating taxes.
